# PR Monitor auto-wake 验收（本 PR）

本分支与它的 PR 只用于验收 Grok App 的 **PR Monitor**，验收完即删，不含产品改动。

## 待更新事项

- [ ] **待更新项**：把下面 `STATUS` 的值由 `PENDING` 改成 `DONE` 后提交并推送。

```
STATUS: PENDING
```

`pr-monitor-acceptance` 这个检查项在 `PENDING` 时刻意失败，改成 `DONE` 后通过；因此「完成本事项」
这一次推送就是一次可预测的 CI 状态迁移（失败 → 通过），再加上一次 PR 更新事件。

## 可用来触发更新的动作

| 动作 | 期望 |
| --- | --- |
| 完成待更新事项并推送 | CI 由失败转通过 → 唤醒会话 |
| 在本 PR 下追加评论 | 新评论 → 唤醒会话 |
| 修改 PR 标题 | 标题变化 → 唤醒会话 |

## 验收要看的三件事

1. 分支区出现 `test/pr-monitor-wake #<n> <标题>`，标题过长要省略。
2. 分支菜单「拉取请求」里能挂上监视，并显示「监视中」。
3. 制造一次更新后，本次会话被唤醒并主动跟进。
