# 集成测试

放置跨模块或经过真实宿主边界的用例，由 `pnpm test:integration` 执行，同时属于 `pnpm test` 的产品回归闸门。

## 准入条件

满足任一条才放在这里：

- 编排两个以上生产模块，验证它们之间的契约，而不是单个函数的输入输出。
- 经过真实边界：启动子进程、读写临时目录、解析真实文件格式、跨进程协议。
- 用真实运行环境验证一个单元测试无法覆盖的时序或资源清理行为。

只测单个纯函数、单个组件渲染或静态源码断言的用例留在 `src/` 同目录。

## 约定

- 导入生产代码统一用 `@/` 别名，避免移动文件后失效。
- 必须自清理临时资源（`afterAll` 中删除临时目录、关闭句柄）。
- 用例要能在 CI 的 Linux/macOS/Windows 上跑；平台差异用 `process.platform` 显式分支。
- 一个文件对应一个可描述的集成场景，文件名用 `<被测场景>.test.ts`。
